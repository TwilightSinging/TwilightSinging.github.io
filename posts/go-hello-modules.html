Go 笔记：从 Hello World 到 Modules

2026-09-28 · Go 笔记 · 占位示例

本文为脚手架占位内容，正式笔记稍后替换。结构示意：概念 → 命令 → 小结。

1. 最小程序

创建一个 hello.go：

package main

import "fmt"

func main() {
    fmt.Println("你好，晚霞")
}

运行：

go run hello.go

2. 用 Modules 管理依赖

在项目根目录初始化模块（模块路径可按自己的仓库改）：

go mod init example.com/hello
go get example.com/some/pkg@latest
go mod tidy

3. 小结（占位）

  • go run 适合快速试跑
  • go mod 是依赖与版本的入口
  • 后续可补充：goroutine、channel、常见踩坑
